> **对应 Gitee 课题**：`#IKSBTX` 众筹叙事的专业合规性（难）  
> **项目定位**：法学与金融科技交叉实证实务，聚焦非法吸收公众存款罪（刑法176条）的司法边界、众筹文案合规审计引擎与重构指引

## 一、 为什么任课老师在此课题标注“（难）”？

在互联网金融创新中，众筹叙事（Pitch / 文案表述）往往是决定一个项目属于**“受鼓励的新质生产力创业”还是“涉嫌触犯刑律的非法集资”**的生死分水岭。

其难点在于：
1. **罪与非罪的极度模糊界限**：
   - 合法众筹（预售商品、创意赞助、无保底预期）；
   - 非法吸收公众存款罪（刑法第176条）：具备**非法性、公开性、利诱性、社会性**四大要件；
   - 集资诈骗罪（刑法第192条）：以非法占有为目的，虚构资金用途。
2. **“打擦边球”与隐蔽利诱**：
   - 实践中大量发起人为了吸引出资，在文案中采用“保本回购”、“消费返利”、“赠送原始股”、“年化收益分成”等隐蔽金融表述，导致合法项目瞬间滑入涉刑深渊。

本项目从司法判例、法理规范与工程审计三个维度全面攻克这一难点：
- 构建了基于最高法法释〔2022〕5号的敏感红线词库 (`src/regulatory_corpus.py`)；
- 开发了自动化合规风险评分引擎 (`src/compliance_checker.py`)；
- 输出了系统化的《众筹文案专业合规重构指南与对照表》。

直接运行综合合规审查套件：
