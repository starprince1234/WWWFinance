## 一、 重要声明与数据真实性界定

1. **原指定数据 (edX 1,000 条教学合成样本)**：
   - 依据原仓库官方 README 明确声明：“*Data for this dataset was generated by edX Boot Camps LLC, and is intended for educational purposes only*”。本研究严格遵照学术诚信，明确将其标注为**教学合成数据集**，绝不冒充真实世界爬取的商业数据。
2. **`Document.docx` 结论复核与重大人为偏差纠正**：
   - 原作者在 `Document.docx` 中提出三条结论：戏剧/剧本绝对数量最高、6-7月夏季最成功、世界音乐（world music）表现最差；
   - 经我们编写算法进行 1000 行全量重新核算证实：戏剧/剧本确实在绝对数量上最高，7月也确实成功数最多；但**原作者关于“world music 是最不成功类别”的论断存在严重口径混淆**——样本中 world music 仅有 3 个项目且**全部成功（成功率 100%）**。原作者显然将“绝对数量最少（3个）”与“成功率最低”混为一谈。真正表现最差的子类别是 `audio`（成功率 0%）。
3. **本地保留的 600 条出版众筹模拟套件**：
   - 本项目保留了 `src/data_generator.py`、`src/eda.py` 与 `src/models.py`，但**严格澄清其为用于教学演示的计量经济学合成样本**，其 Logit 与 OLS 模型仅展示统计推断方法，不代表真实图书众筹市场的因果效应。

## 三、 快速复现与验证步骤

### 1. 独立运行原版工作簿 1000 样本深度核算与纠错
```bash
python3 projects/05_crowdfunding_books_analysis/src/analyze_original_workbook.py
```
**输出**：即时输出 1000 样本全局分布、交叉表、world music 专项检查、12 档目标区间 COUNTIFS 统计、以及均值/中位数/方差描述性统计。

### 2. 生成终版全功能 Excel 工作簿 (含修复后的公式与统计表)
```bash
python3 projects/05_crowdfunding_books_analysis/src/build_full_workbook.py
```
**输出**：在 `data/` 目录下生成 `CrowdfundingBook_Full_Analysis.xlsx`，完美解决 `#DIV/0!` 异常，嵌入完整的 `Crowdfunding Goal Analysis`（12 档目标区间及比例公式）和 `Statistical Analysis`（均值、中位数、方差、标准差）。

### 3. 运行本地计量经济学模型演示 (Logit / OLS)
```bash
python3 projects/05_crowdfunding_books_analysis/tests/run_analysis.py
```
